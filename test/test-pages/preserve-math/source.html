Preserving mathematical formulas in Reader View

Site navigation, comments and other chrome that Readability drops.

This article explains several formulas. A native inline MathML expression x 2 appears inside running text, while a block-level expression with a TeX annotation follows on its own line:

1 2 \frac{1}{2} one half visual copy

MathJax stores inline TeX in a script tag and display TeX in a script tag with an explicit mode: Both have to survive as inert text rather than executable scripts.

KaTeX emits two parallel layers, an accessible MathML layer and an aria-hidden visual approximation. The inline marker a + b a+b a + b is followed by a display marker: y = 3 y=3 visual copy

Hostile TeX must stay inert text and must never execute or create a script, image or other element. The payload uses a javascript URL and TeX control sequences, all of which have to remain literal text: whereas an ordinary script and its are removed like on any other page.
