MathJax stores inline TeX in a script tag E=mc^2 and display TeX in a script tag with an explicit mode: 

\int_{0}^{1} x\,dx
Both have to survive as inert text rather than executable scripts.

KaTeX emits two parallel layers, an accessible MathML layer and an aria-hidden visual approximation. The inline marker a + b is followed by a display marker: y = 3

Hostile TeX must stay inert text and must never execute or create a script, image or other element. The payload uses a javascript URL and TeX control sequences, all of which have to remain literal text: \href{javascript:alert(1)}{\texttt{x}} \frac{1}{2} whereas an ordinary script and its are removed like on any other page.
